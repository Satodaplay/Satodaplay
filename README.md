### 🖥️ MeloScreen

Uno de los proyectos más importantes que estoy haciendo ahora mismo.

**MeloScreen** es un sistema de cartelería digital montado sobre Raspberry Pi para que una pantalla pueda funcionar sola de forma estable y remota.

Incluye cosas como:

- reproducción de imágenes y vídeos
- sincronización de contenido
- caché local
- funcionamiento aunque falle internet
- conexión por WireGuard
- control remoto
- varios dispositivos
- logs
- automatización
- panel de administración

Es de los proyectos donde más estoy mezclando desarrollo, Linux, redes y hardware.
