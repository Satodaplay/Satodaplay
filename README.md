## 🖥️ MeloScreen

Uno de los proyectos principales que estoy haciendo ahora mismo.

**MeloScreen** es un sistema de cartelería digital montado principalmente sobre Raspberry Pi.

La idea es poder poner una Raspberry detrás de una pantalla y que se encargue de reproducir contenido de forma automática y estable.

Tiene cosas como:

* reproducción de imágenes y vídeos
* sincronización de contenido
* contenido guardado en local
* funcionamiento aunque falle la conexión
* conexión por WireGuard
* control remoto
* varios dispositivos
* caché
* logs
* automatización
* administración desde un panel

Es probablemente uno de los proyectos donde más cosas diferentes he tenido que juntar.

Linux, redes, Raspberry Pi, almacenamiento, programación, servidores y reproducción multimedia.
